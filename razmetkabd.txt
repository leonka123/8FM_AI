Открытая база данных «8 ФИЗМАТОВ»
17 октября в 17:50
Версия схемы: 2. Формат: JSON, кодировка UTF-8. Файл доступен через /database.
Это снимок состояния на момент timestamp, а не поток обновлений. По запросу файл обновляется, если ему исполнилось восемь часов. До этого бот отправляет ту же версию. Скрытые сведения об активных играх не публикуются.
Как читать схему
integer — целое число; number — число JSON, целое или дробное; boolean — true/false; string — строка; object — объект; array<T> — массив элементов T. Запись number/null разрешает также null.
В колонке «Наличие»: да — поле обязательно в указанном объекте; из источника — поле включено, только если сохранено во внутренней записи; условно — условие описано в таблице. Отсутствующее поле и null различаются: отсутствие означает, что сведений нет или они скрыты; null — явно сохранённое неизвестное значение либо скрытый идентификатор закрытой карты.
[] в пути означает элемент массива, <player_id> — динамический ключ объекта. Все идентификаторы игроков — строки: обычно десятичный Telegram ID, у игровых ботов возможны значения вроде bot_gena. Не преобразовывайте все ключи игроков в числа. Имя — публичное игровое имя, оно может не совпадать с Telegram username и не обязано быть уникальным.
Номера игр начинаются с единицы и совпадают с номерами в боте: games[0].id == 1, эта игра открывается командой /replay_1. ID игры равен её индексу в games плюс 1; отменённые записи сохраняются, чтобы ссылки не сдвигались. Такая же нумерация применяется к play_again_game, ссылкам на игры в профилях и спискам игр лиг.
Индексы сезонов, этапов, ходов, мест и настроек сохраняют внутреннюю нумерацию с нуля. Например, индекс сезона — его позиция в leagues.archive. Telegram ID и строковые ID игроков не изменяются. Все отметки времени — Unix timestamp в секундах; часовой пояс не кодируется в числе.
Корень файла
schema_version — тип: integer; наличие: да; значение: Версия публичной схемы, сейчас 2.
timestamp — тип: number; наличие: да; значение: Время создания снимка; не время последней отправки в Telegram.
games — тип: array<object>; наличие: да; значение: Все записи игр в исходном порядке, включая отменённые.
users — тип: object; наличие: да; значение: Публичные профили по ключу <player_id>.
leagues — тип: object; наличие: да; значение: Архив сезонов и публичная регистрация.
Количество игроков в сообщении — len(users), игр — len(games), сезонов — len(leagues.archive). Игры включают все статусы; сезоны включают текущий, даже пустой. Число игроков означает число профилей, а не число участников конкретной лиги.
Игры: games[]
id — тип: integer; наличие: да; значение: Номер игры с единицы, равен индексу в массиве плюс 1. Совпадает с номером в /replay_ID.
status — тип: string; наличие: да; значение: WAITING, ACTIVE, FINISHED, STOPPED, CANCELED. Неизвестные будущие статусы обрабатывайте отдельно.
players — тип: array<string>/object; наличие: из источника; значение: В WAITING — список ID; после запуска — объект по ID игроков.
arrangement — тип: array<string>; наличие: из источника; значение: Порядок рассадки игроков; соседство циклическое.
metadata — тип: object; наличие: из источника; значение: Параметры и даты игры.
move — тип: object; наличие: из источника; значение: Состояние текущего хода; есть в активных и части остановленных/старых записей.
cards — тип: array<array<array<string/null>>>; наличие: условно; значение: Только FINISHED/STOPPED, если сохранена раздача: раунд → начальная рука → карты. Позиция руки соответствует исходной рассадке, а не текущему владельцу после передачи рук.
play_again_game — тип: integer; наличие: из источника; значение: Номер комнаты для повторной игры, с единицы.
Отменённая запись может состоять только из id и status. STOPPED — окончательно остановленная игра, она может иметь неполную историю; раздачи и выбранные карты доступны для её разбора. Для незнакомого статуса раздача и история выборов не экспортируются.
Параметры: games[].metadata
is_rated — тип: boolean; наличие: из источника; значение: Влияет ли игра на ELO. Старые 0/1 приведены к boolean.
timer_id — тип: integer; наличие: из источника; значение: Индекс настройки времени: 0 — стандарт, 1 — рапид, 2 — блиц, 3 — пуля, 4 — ультрапуля.
deck — тип: object; наличие: из источника; значение: Использованная колода и её версия.
deck.id — тип: integer; наличие: из источника; значение: Внутренний индекс колоды; возможен исторический -1.
deck.version — тип: string; наличие: из источника; значение: Версия набора карт на момент создания игры.
created_at — тип: number/null; наличие: из источника; значение: Время создания комнаты. При запуске комнаты может не сохраниться в новой записи игры.
started_at — тип: number/null; наличие: из источника; значение: Время начала игры.
finished_at — тип: number/null; наличие: из источника; значение: Время завершения игры. В старом архиве встречается null.
stopped_at — тип: number/null; наличие: из источника; значение: Время остановки игры.
modifiers — тип: array<string>; наличие: из источника; значение: Коды модификаторов: im_chislov, upgrade, meteors, foggy_debut, easter, lottery; список может расширяться.
tournament — тип: boolean; наличие: из источника; значение: Признак турнирной игры. Отдельная база турниров в файл не входит.
league — тип: object; наличие: из источника; значение: Принадлежность к лиге.
league.season — тип: integer; наличие: из источника; значение: Индекс сезона в leagues.archive.
league.tier — тип: integer; наличие: из источника; значение: Внутренний код дивизиона/кубкового соревнования; это не место игрока.
league.match — тип: integer; наличие: из источника; значение: Внутренний индекс матча/этапа данного соревнования.
brigantina — тип: object; наличие: из источника; значение: Принадлежность к Кубку Бригантины.
brigantina.stage — тип: integer; наличие: из источника; значение: Индекс этапа.
brigantina.match — тип: integer; наличие: из источника; значение: Индекс матча.
Карточный справочник и тексты правил не входят в файл. Значения карточных кодов интерпретируйте по соответствующим deck.id и deck.version.
Текущий ход: games[].move
round — тип: integer; наличие: из источника; значение: Индекс раунда, обычно 0 или 1.
card — тип: integer; наличие: из источника; значение: Индекс хода в раунде. Сводный индекс истории: round * 5 + card.
started_at — тип: number/null; наличие: из источника; значение: Время начала текущего хода.
remaining_players — тип: integer; наличие: из источника; значение: Сколько игроков ещё выбирают карту. Старые записи могут не содержать поле.
Участник: games[].players.<player_id>
Этот объект используется, когда players — объект, а не список ожидающей комнаты.
status — тип: string; наличие: из источника; значение: CHOOSING — выбирает; AWAITING — выбор сделан. В завершённых играх обычно отсутствует.
moves — тип: array<object>; наличие: условно; значение: В ACTIVE есть всегда; в FINISHED/STOPPED — если сохранено. Элементы идут по порядку ходов.
rating — тип: object; наличие: условно; значение: Только FINISHED/STOPPED, если сохранён рейтинг участника.
rating.old — тип: number/null; наличие: из источника; значение: ELO перед игрой.
rating.new — тип: number/null; наличие: из источника; значение: ELO после игры; в остановленной игре может отсутствовать.
История: games[].players.<player_id>.moves[]
Для активной игры элементы с индексом меньше round * 5 + card — завершённые ходы. Если игрок выбрал карту текущего хода, появляется элемент только {"submitted": true}. Его наличие показывает факт выбора, но не раскрывает карту, открытый/закрытый способ розыгрыша или параметры эффекта. Если выбор ещё не сделан, дополнительного элемента нет. Снимок фиксирует состояние на timestamp, игрок может отменить свой выбор позже.
У завершённого активного хода закрытая карта записана с card_id: null, открытая — с настоящим кодом. При foggy_debut, пока завершено меньше двух ходов, уже сделанные ходы также представлены только {"submitted": true}. После раскрытия дебюта применяется обычная схема. Раздачи активной игры отсутствуют целиком, включая второй раунд.
submitted — тип: boolean; наличие: условно; значение: Всегда true. Единственное поле скрытого элемента активной истории. В остальных элементах отсутствует.
card_id — тип: string/null; наличие: условно; значение: У обычного завершённого активного хода есть всегда; у архивного — из источника. В активной игре закрытая карта всегда null; в архиве код может сохраниться либо быть неизвестен. Код может содержать суффикс модификаторов, например .M или .E.
is_closed — тип: boolean; наличие: условно; значение: Обычный завершённый активный ход или архивный ход, если поле сохранено. true — карта закрыта. У скрытого элемента отсутствует.
score — тип: number; наличие: условно; значение: Сохранённый накопленный счёт после этого хода. Только раскрытый завершённый активный ход либо архив. Может отсутствовать у незавершённого архивного хода.
m_direction — тип: integer; наличие: условно; значение: Направление метеоритного эффекта, -1 или 1; если сохранено у раскрытого завершённого хода либо в архиве.
lottery — тип: integer; наличие: условно; значение: Результат лотереи, обычно 1–3; если сохранено у раскрытого завершённого хода либо в архиве.
order — тип: integer; наличие: условно; значение: Только FINISHED/STOPPED: индекс выбранной карты в руке, если сохранён.
auto — тип: string; наличие: условно; значение: Только FINISHED/STOPPED: сохранённый алгоритм автоматического выбора, например skip или greedy.
null у закрытой карты — не код карты и не надёжный признак просрочки. Не пытайтесь по отсутствующим значениям восстанавливать счётчик пропусков. В старых играх часть раздач, дат и рейтингов не сохранялась; экспорт не придумывает эти данные.
Профили: users.<player_id>
Все поля профиля включаются из источника. У современных профилей обычно заполнены все основные поля; у неполной старой записи поля могут отсутствовать.
name — тип: string/null; наличие: из источника; значение: Публичное игровое имя.
elo — тип: number; наличие: из источника; значение: Текущий ELO.
max_elo — тип: number; наличие: из источника; значение: Максимальный сохранённый ELO.
played_rated — тип: boolean; наличие: из источника; значение: Участвовал ли профиль в рейтинговых играх.
wins — тип: integer; наличие: из источника; значение: Сохранённое число побед.
ke — тип: number; наличие: из источника; значение: Суммарный КЭ.
ka — тип: number; наличие: из источника; значение: Суммарный КА.
first_places — тип: integer; наличие: из источника; значение: Сохранённый счётчик первых мест; экспорт не пересчитывает его.
max_prestige — тип: number; наличие: из источника; значение: Максимальный сохранённый престиж.
games — тип: object; наличие: из источника; значение: Ссылки на игры профиля.
games.active — тип: array<object>; наличие: из источника; значение: Активные игры по данным профиля.
games.active[].id — тип: integer; наличие: из источника; значение: Номер игры с единицы.
games.finished — тип: array<object>; наличие: из источника; значение: Завершённые игры, учтённые в профиле.
games.finished[].id — тип: integer; наличие: из источника; значение: Номер игры с единицы.
games.finished[].place — тип: integer; наличие: из источника; значение: Итоговое место с нуля; при ничьей возможно одинаковое место.
awards — тип: object; наличие: из источника; значение: Публичные награды; допустимые категории перечислены ниже.
Это сохранённые показатели профиля, а не результат повторного расчёта по games. Например, не все игры с малым числом участников учитываются в статистике профиля. Для проверки актуального статуса игры используйте games[id - 1].status.

archive[].players.<player_id>.prestige — тип: number; наличие: из источника; значение: Сезонный престиж.
archive[].players.<player_id>.ke — тип: number; наличие: из источника; значение: Сезонный суммарный КЭ.
archive[].players.<player_id>.ka — тип: number; наличие: из источника; значение: Сезонный суммарный КА.

registration.<player_id>.participate — тип: boolean; наличие: из источника; значение: Заявлено ли участие в текущем сезоне.
registration.<player_id>.tier — тип: integer; наличие: из источника; значение: Код зарегистрированного дивизиона.
Коды дивизионов/кубков принадлежат правилам соответствующего сезона. Не считайте tier порядковым местом или непрерывной шкалой. У старых сезонов и игр возможны неполные связи: экспорт переводит ссылки на игры в нумерацию с единицы, но не создаёт отсутствующие профили/матчи.
Пример активной истории
{
  "status": "AWAITING",
  "moves": [
    {"card_id": "A", "is_closed": false, "score": 3},
    {"card_id": null, "is_closed": true, "score": 5},
    {"submitted": true}
  ]
}
Первые два хода завершены, третий выбор сделан, но ещё не раскрыт. Значение A здесь условное. В активной игре невозможно получить раздачу или узнать, какую карту скрывает последний элемент.
Совместимость
В файле перечислены только поля публичной схемы. Новые внутренние поля автоматически в экспорт не попадают. Неизвестные публичные поля в будущих версиях лучше игнорировать; при несовместимом изменении необходимо учитывать schema_version. В версии 1 номера игр и ссылки на них начинались с нуля; в версии 2 они увеличены на 1. При смене версии бот автоматически пересоздаёт кеш, даже если восемь часов ещё не прошли. Telegram file_id, сведения об отправленных сообщениях, причины блокировок и технические данные кеша не являются частью этого формата.
